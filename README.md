## Анализ файла с координатами и геоданными

### Описание содержимого

Данный файл содержит:
* **Географические координаты** в различных форматах
* **Геоданные** с использованием Natasha и Yargy
* **Функции конвертации** координат из DMS в DD
* **Парсеры** для извлечения географических сущностей

### Основные компоненты

#### Импортируемые библиотеки
* **Natasha** для обработки русского текста
* **Yargy** для создания грамматик
* **Pandas** для работы с данными
* **Regex** для поиска паттернов

#### Основные функции
* Конвертация координат из DMS в DD
* Извлечение географических сущностей
* Парсинг различных форматов координат

### Структура данных

Файл содержит:
* **Координаты** в форматах:
  * DMS (градусы-минуты-секунды)
  * DM (градусы-минуты)
  * DD (десятичные градусы)
* **Географические объекты**, извлеченные с помощью:
  * Natasha NER
  * Yargy-парсеров

### Рекомендации по использованию

1. Для работы с файлом необходимо:
   * Установить зависимости: `pip install natasha yargy pandas`
   * Иметь данные в поддерживаемом формате координат

2. Основные шаги обработки:
   * Извлечение координат из текста
   * Конвертация в единый формат
   * Парсинг географических сущностей
   * Сохранение результатов в DataFrame
